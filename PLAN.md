# FredTalk distribution plan

1. Export the active Skill, current source projects, 177 visible references and 288 historical identities into a clean repository.
2. Remove repository histories, credentials, local reviews, user paths, raw recordings and redundant archives. Keep FredTalk branding and illustrative characters.
3. Deduplicate binary assets by SHA-256. Audit text with a secret scanner and inspect media for account information. Only reviewed assets enter downloadable packs.
4. Provide a small bundled demo, local library server, catalog CLI and checksum-verified optional asset installer. No machine-specific paths or mandatory cloud server.
5. Write parallel English/Chinese READMEs, architecture, reuse guide, security notes and an explicit public-release checklist.
6. Test a clean checkout. Create a private FredTalk repository and private release assets with gh/git. Verify visibility and remote content.

Public hosting and changing repository visibility are separate future actions. No third-party media/font license is implied by its inclusion in this private review repository.
