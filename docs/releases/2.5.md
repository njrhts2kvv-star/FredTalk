## 制作方法

- 逐句规划对象、变化、证据、观看焦点与交接对象；增加好坏成对样例和整期简报。
- 录屏先展示产品，再推近操作与结果；强调跟随口播；段与段保持对象连续。
- 新增基于 macOS Vision 的可读性检查，与动态检查和实际视觉审看配合。
- 补齐整期骨架、通用共享件、1080p30 预览、时基核对及局部重渲方法。
- kit v4 加入无过冲落定与按帧率换算的音效时长。
