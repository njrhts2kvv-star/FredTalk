适用：用户指定 Library 动效；实景/录屏转关键词、再转人物；大字与人物的前后景；媒体窗口质感。它是可选动作语法，不是新的全局外观，也不覆盖当前用户指令、批准基线或 noFade 等合同。

B01–B08 定位于用户关注区间；B09–B14 是研究补充候选。二者均不是 Fred 已批准成片或组件，不写入 approval-ledger。研究片保留第三方原音、文字、品牌、人物，不是正式生产资产；本地保存不等于可自动上传到外部生成平台。正式运行依赖仍从项目 skills/ 解析。

## 先决定注意力交给谁

常见链条是“真实证据 → 文字提炼 → 人物判断 → 下一证据”，但不强制每段走完。

| 当前语义 | 可选交接 | 参考 |
|---|---|---|
| 从操作提炼结论 | 实景降级，少量关键词清楚；读完再给人物或回证据 | B03、B10 |
| 列表仍要读，人物点评 | 完整面板等比缩小、侧移让位；保持文字清楚 | B02 |
| 目录已读完，转疑问或引导 | 文字窗口退后虚化，人物前景接管；旧层适时退出 | B04 |
| 总结后继续演示 | 关键词退出，同一真实证据恢复清楚 | B09、B10 |
| 多份素材/多个结果 | 层叠表达数量、焦点表达主次，按关系重排 | B05、B11、B13 |
| 演示后的主观收束 | 证据退后，人物承担总结 | B14 |

在人物进入前判断旧内容是否仍有阅读任务。仍要读：缩小让位但保持清晰；已读完：可以降级或遮挡，并在下一段开始前退出。不能把上一段全部文字一直压在人物后面。

## 三种不同的蒙版职责

- **裁切**：媒体收进圆角窗口，不改变真实内容。
- **背景降级**：仅旧媒体/旧文字层虚化或降低对比，当前前景字保持清楚；不是整屏灰雾。
- **前后遮挡/对焦交接**：新的主体接管后，旧主体按语义结束。只有已读内容允许被遮挡。

不要把“蒙版文字”自动翻译成“视频填进字形”；本次重点参考片段更接近背景虚化与前景文字叠层。无源工程时只说明可见结果，具体实现标为场景实现建议。

B03 源片确有逐项淡化，B04 有上下对向退场和短空白。学习焦点接力，不把所有参考片段细节设为 Fred 默认；当前合同禁止长淡化时用短遮罩、短位移或切换重建。空场需由录音/衔接解释，不照搬参考时长。

## 媒体外框质感

参考 B07：媒体内容、圆角裁切和外侧投影分层。外部留白建立舞台；局部阴影说明离底面的高度；框稳定而内部真实视频继续运动。

建议实现为外层布局/阴影、内层裁切、真实媒体三层，避免 overflow 裁掉投影。具体圆角、阴影与边距需用 Fred 样片校准，不冒称从 Library 工程测得。不要复制播放器控件、Quick Look 灰边或无因装饰。

## H3 方向 → Remotion 精确场景实现

H3 用于验证视觉方向、连续载体变化和镜头节奏。Remotion 重建文字、布局、蒙版、音频节拍，并合成已有自有人物动作；Remotion 不会凭空创造人物表演。

人物不必在 H3 阶段生成。无人物方向也要明确后期人物的位置、入场语义锚点、哪块面板让位和最终接给谁；不能最后随便贴人。实际人物从项目 `skills/fred-remake/assets/characters/manifest.json` 选，观看所选原动作、检查本地实体与整个运动包络；不截取 Library 人物作为 Fred 素材。

先用完整逐字稿/录音决定少量、分散且动作不同的人物候选。不要把单一参考链套遍整期，也不要因为有新参考提高人物频率。录音才是时钟，研究片长不构成新视频的固定时长。

真实 UI 操作与结果来自实录；关键词来自当前稿件。H3 近似 UI 不是功能证据。录屏两侧的逐字稿段落仍保持各自边界，剪辑层可用真实尾帧/截图衔接，不为转场合并口播。

## 保留 Fred 的外观与批准边界

当前已确认字体为 MiSans 500/600、自然中文间距；黑白基底与当前强调色按当次合同。Library 的超粗挤字、彩色词云、重投影、窗控彩点和装饰线不自动继承。局部景深可以有职责，不能泛化为全局灰雾。

参考是动作关系，不是要求每页相同。新方向仍需按现有 H3/Remotion 流程验证文字、遮挡、时间、首尾衔接、完整样片与正式门禁；研究片解码通过不等于场景实现已批准。
