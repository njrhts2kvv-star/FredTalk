# 音效系统

音效只服务可见动作：`pop/啪/啵` 用于主词或结论锁定，`swipe/whoosh/刷/划过` 用于横线和位移交接，`click/嘟/点击` 用于节点或清单追加。长拖拽使用足够长且可听见的 whoosh。

动作起帧与音效起点严格同步；同一认知动作通常一个音效，不给每个字配声。不要在尾部加亮音、叮声或任务完成音。正式口播为主声道，音效只做瞬态提示，必要时 ducking。

无正式口播时，动作音效峰值可从约 -25dB 到 -19dB 起步；混入口播后按听感继续降低。验收：存在 AAC 音轨；声道非全静音且不是 `-inf`；合同 cue 附近有能量峰；没有超出动作的无因峰；头尾无爆音；音量不压口播。优先使用 episode 公共音效库中的 `点击.WAV`、`鼠标点击.WAV`、`划过.WAV`、`滚动.mp3`、`啵.WAV`、`打印机.WAV`；`任务完成.WAV` 仅在语义确实完成任务时使用，并记录源文件和 checksum。
