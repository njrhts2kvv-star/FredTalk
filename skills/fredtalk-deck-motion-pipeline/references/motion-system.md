# 动效系统

路由：`语义关系 → topology → visual carrier → motion energy → final frame → effectId`。不要按页码、stableId、关键词或数组轮换选效果。

每个 step 只完成一个认知事件。推荐快速遮罩、水平切入、18–32px 短位移、逐词建立、同槽替换、旧信息让位、横线锁定和结构重排；一页一个主动作、至多一个辅助动作。

禁止缓慢淡入/淡出、长距离上下刷字、整页漂浮、无信息弹跳、旋转、横向压缩、循环呼吸、扫描线残留和花哨粒子。颗粒感只能短暂用于文字建立，终态必须清晰准确。

## 载体入场与受控弹性

Fred 明确偏好页面载体和内部模块有可感知的入场，尤其是点到面、小窗口到大场域、模块吸附、卡片合并和容器锁定。这些动作可以有短促弹性，让对象看起来有重量和接触感。

使用原则：

- 弹性发生在主运动的末端，常规只超调一次，随后迅速静止。
- 超调幅度要小：缩放通常约 `1.01–1.04`，位移只是末端的少量回拉，不能多次摇摆。
- 大场域扩展偏稳重，小模块就位可略灵敏；不能全页所有元素同时使用同一弹簧。
- 先动载体，再按口播语序建立文字或内部模块。如果载体未就位，文字不能跨边界或被裁切。
- 动效必须有语义：进入、就位、吸附、合并、锁定或结论落地。如果只是“看起来更动”，就不使用弹性。
- 弹性会影响排版安全区；超调帧也要检查文字不压模块、不出界、不闪跳。
- 配音效时，whoosh 对应进入和扩展，pop/click 对应就位或锁定；声音不能早于可见动作。

检查 0%、20%、50%、80%、结论帧和最终帧。把关键帧写成事件序列并与 `spokenOrder` 对照；检查遗漏、倒序、错误并行、方向错误、双线、缺角、遮罩/指针残留和最终闪跳。

## 大胶囊空间接管

- 先由点、窗口、面板或多个模块建立前提，再让主胶囊扩展、合并或覆盖原空间并承载结论。
- 扩展必须改变视觉中心和信息层级，不能只是给一句话套圆角底。
- 使用一次短促超调后稳定；结果按口播留足阅读时间，不无因回缩、呼吸或漂浮。
- 强调色按当前功能或重点稀疏使用，不因发生接管就必须染紫。
- 设备、人物、真实 UI 或路径拓扑若没有结论接管，不强行改造成胶囊。
