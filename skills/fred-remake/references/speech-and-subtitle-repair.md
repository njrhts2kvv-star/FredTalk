# 口播时钟、字幕避让与音效局部返修

适用：用户认可整体效果，只要求动画贴合录音、文字避开外加字幕，或禁用指定音效。保持设计与声音请求的边界，不自动剪口播、烧字幕或添加旁白。

## 录音是动作时钟，不一定是成片音轨

- 锁定本次录音与 SRT 的真实版本、checksum、起点偏移及段落边界。SRT 是定位线索；用录音核对关键词、停顿与字幕偏差，不按字数平均分时长，也不自动改写锁定文案。
- 建立 `spoken cue → output frame → source frame/state` 映射，逐段记录 fps 和时间单位。后续仅改位置/音效时，对比 Manifest 的锚点、段落偏移、总帧数与保留事件，保证没有意外变速或漂移。
- 分段重映射进入离散 `Sequence` / 视频选帧边界时，明确整帧量化策略，在边界前后及全部输出帧检查预期活动片段数量，防止小数帧落在两个区间之间造成空场。连续几何插值仍可使用浮点数，不对所有动画盲目取整。
- 录音仅用作节奏参考还是需要混入输出，由当前音轨合同决定。画面可使用 `Freeze` 映射源时钟；随成片播放的音效须绑定输出时钟，不能无意放进被冻结/重映射的子树。

## 字幕安全区检查的是整个运动包络

1. 从实际字幕模板、用户截图或目标合成画面确定安全区，并换算到最终画布坐标。未知时记录临时预留假设；某一期的比例、像素坐标和上移距离不作为公共默认值。不因用户说“挡字幕”就额外烧录字幕。
2. 以语义对象审计两段/全部受影响页面：底部结论、状态徽章、流程标签、共享组件、`Freeze` 保留首态、下一场重复实现，以及烘焙进视频/图片的文字。位图文字需独立评估，不能假设修改 JSX 会同步修改原视频。
3. 优先移动点名标签到已有留白，保持字号、字重、文案及出现/退出 cue。上移 SVG 文字时同步移动其 reveal `clipPath`；检查父级缩放、transform-origin、translate、遮罩和基线，不只修改静态 top/y。
4. 检查入场到退场的全部可见 bbox、最大缩放和相邻标签交接。终态不挡字幕不代表入场不会从字幕区穿过；上移后也可能撞到上方标题、人物节点或即将进入的旧/新标签。
5. 测试调用实际生产帧状态函数或测量真实渲染 DOM/图像，不把新坐标另抄进测试后自证通过。低分辨率诊断覆盖入场、中间态、终态与交接；最终编码后再次提取同一时点检查。

全屏背景、调暗蒙版和场景过渡覆盖完整画布，包括字幕带；只有关键前景内容避让。不能将整屏遮罩嵌套进字幕安全容器而留下底部白带。

“加快节奏”先缩短空等和重复建立，保留关键句阅读与成果停留；内部演示只需一次清楚变化时，不反复换结果。不要用统一倍速解决所有段落。

## 禁用指定音效不等于删除素材或取消动作

- 本次任务登记禁用的真实资产身份：原名、运行时别名/路径，必要时 checksum；检查全部 active page 的事件、共享声音层和内嵌视频原音轨，不只搜索显示文件名。
- 只移除对应事件，保留其他声音的时点、增益及动画本身。没有用户授权不删除源音效，也不把单次禁用偏好扩散成跨期永久黑名单。
- 核对生产组件真正读取的事件清单；未被引用的旧清单不能证明声音仍在或已移除。保留源视频时显式检查 muted/volume，避免从参考片段混回禁用声音。
- 画面补帧不需要改声音时优先保留原音轨；兼容时 stream copy，并用音频包 hash 或解码 PCM 比较验证。容器/文件 hash 改变不表示声音改变，文件时长也不能代替音轨核对。

## 字体就绪与隔离版本

- 字体加载的等待句柄绑定稳定的 composition 生命周期；成功释放，失败取消并报错。不要依赖模块级一次性等待去管理会重新挂载的组件，也不要通过卸载重建字体节点来碰运气消除超时。
- 新版本只复制所需源码、合同与引用，媒体保持受控引用；不要连旧 QC、失败视频和缓存一起递归复制。核对软链接真实目标和剩余空间，冻结范围覆盖跨目录导入与实际素材，不只 hash 入口源码目录。
