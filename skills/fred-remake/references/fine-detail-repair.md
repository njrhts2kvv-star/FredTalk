# 局部精细场景实现：字体、短强调与连续状态

适用：用户说“整体不错，但字体/闪光/内部缩放不像”或要求像素级识别差异。先保留已认可的运动骨架，再修失败维度；不是所有视频都要套用以下效果。

## 先把差异变成可验证项

按对象记录 `referenceTime/outputTime、sourceFrame/PTS、ROI、差异、preserve/change、验收帧范围`。同一语义事件先对齐时刻，再比位置和字形；记录真实源 fps，不能把 24fps 帧号直接当作 60fps 帧号。

- 全片疏采样仅定位事件。四角闪线、描边闭合、蓝圈脉冲、揭示边缘等短动作，用原生帧率提取包含前后余量的连续帧；再播放核对。低频 contact sheet 会漏掉只持续数帧的动作。
- 把“闪”分类：有意的局部强调、入场由灰到黑、路径亮起，或非预期的整屏/字形频闪。前者按参考片段重建，后者排查渲染。不能把所有闪光删掉，也不能为补闪光新增连续闪烁。
- 分开记录主动作和附属效果：对象/触发时刻/持续时间/位置/数量/颜色或线宽变化/清除时刻。例如描边闭合、标题上浮、角上短线和圈体脉冲不是一个统一 scale 或 fade。
- 一次只修一个已确认差异，复核后再组合。没有证据的效果不补，参考片段生成瑕疵不自动继承。

## 字体的局部像素测量

1. 冻结同一准确文字、字体文件、加载完成状态和代表性稳定帧。先按正文、卡片标题、权限标签、结论等职责分别选字重，不把一次 Medium→Heavy 的尝试扩散到整段。
2. 统一比较尺度、颜色空间和采样方式；明确源图与输出的画幅适配。记可见文字 bbox、可见高度、宽高比和相邻留白，不直接拿不同分辨率的原始宽度比较。
3. ROI 只包住待测文字，排除卡片边框、背景线、相邻文字、阴影和未完全显现的遮罩。bbox 突然变宽/变高时先检查污染，不立刻改字体。
4. 可辅助测量 `inkFraction = ROI 内深色文字像素数 / 文字紧包围框面积`。记录阈值、帧时刻、ROI、字体候选和结果，并检查合理阈值变化是否改变结论。反白字或彩字需另定义前景分割，不套深色阈值。
5. 笔画占比受字距、字形、压缩与抗锯齿影响，不能单凭它认定字体相同；不能把该比例或其误差下降称作“场景实现相似度”。将 ROI/遮罩可视化后，结合字形、字重、bbox 和正常播放选择候选。
6. 先筛 family/实际字重，再调字号与自然字距。较粗候选超过参考时回退，不追求越粗越好；不要把某次片段的字体等级、负字距、阈值或目标比例设成跨期默认值。
7. 参考片段字形由生成模型扭曲时，记录剩余差异，优先保持正确字形与可读性。没有源字体/实现不能承诺全片逐像素一致。

## 检查整个运动区间，而非几个终点

- 嵌套缩放：分别测父外壳与内部胶囊/卡片在起点、中间态和终点的尺寸比；记录缩放中心。外壳变小不代表内部变化足够明显。
- 共享路径：圆点和被画出的边框使用同一几何与路径进度；核对转弯、方向和闭合时刻。
- 标题与卡片：在共同运动的世界/屏幕坐标系计算可见 bbox，检查整个入场区间的最小间距。不要仅在终态发现“没有重叠”就放行；字体变粗、放大或结论提前入场后重新检查。
- 语义上同一个焦点圈/选框交接时，优先保留一个稳定节点；必须用两个节点时，显示区间互斥，并匹配交接两侧的位置、尺寸、描边与光晕。加粗旧圈后，原先不显眼的短暂双圈也会变明显。
- 媒体槽：固定容器几何并保持素材宽高比，检查过渡中间态有没有横图突然变成竖图、裁掉内容或一分为二。
- 结尾：覆盖从“最后一次布局变化开始”到真实尾帧的整段，而非只比较最后两帧。确认拉远过程中标题不碰卡片、临时线圈清除、当前结论保留。
- 几何/时间测试应调用生产实现使用的帧状态函数或测实际渲染帧。只断言源码包含某个字符串、把常量另抄一遍再测试，不能证明真实组件不重叠。

## 把验证做在便宜的阶段

字重候选先做受门禁约束的局部 still 对比；短强调和交接先做局部低分辨率运动测试。它们是诊断，不是用户批准样片。默认局部修好后导出完整 1080p 样片，播放检查未修改区间，再请用户确认；用户已经认可完整样片且明确授权有限修改后直接出片时，遵循 [批准边界](gates-and-delivery.md#已认可样片且明确要求有限修改后直接出片)，不重复索要确认，也不省略内部复检。

已发现的问题应在正式出片前一起关闭。不要“改一处→完整 4K→发现一处→再完整 4K”作为默认迭代。最终 4K 仍必须复验，预览没有发现不代表最终编码必然正确。
