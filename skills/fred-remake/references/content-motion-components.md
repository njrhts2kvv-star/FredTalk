# 可适配的内容与运动组件

源文件在 `assets/content-motion/ContentMotion.tsx`，纯状态函数在 `motion-state.mjs`。它们是从认可运动和分层方法提取的新适配实现，不是原版像素场景实现，也没有继承原版的新片批准。

| 组件 | 职责 | 内容/时间由调用者提供 |
| --- | --- | --- |
| SoftSurface / ContentClip | 无描边表面、阴影与内部揭示分层 | box、fill、shadow、progress；不对表面父层加 reveal |
| TranscriptSelection | 正文中的局部选中与光标 | 真实 lines、字符范围、字号；不补宣传标题或工具栏 |
| WaveformTrack | 波形、选区、播放头与同一比例的刻度 | 已归一化的真实音频 samples、总时长、当前位置 |
| BranchFocus | 展开多个对象，聚焦其中一个 | origin、targets、selected、展开和聚焦时段 |
| ExpandReturn | 当前表面放大讲解后返回 | rest、expanded、open、close |
| SlotReplace | 同一槽位按 cue 替换完整内容 | ordered items 和自定义 render |
| FocusStage | 支撑内容缩小退后、重点前置 | 两层内容、progress；不默认黑窗口 |
| FrostedFocus | 原场景位置/尺度不变，毛玻璃层托起清晰重点 | background、foreground、progress、light/dark tone、blur、tintOpacity；不内置文字和时间 |
| ObjectHandoff | 表面持续存在，几何与内容分别交接 | from、to、travel、swap、前后内容 |
| ViewportMask | 覆盖完整画布的过渡 | 放在全画布层，不能嵌套字幕裁切容器 |

调用者使用 `useCurrentFrame()/fps` 提供秒钟；没有固定 0.7 秒节拍、全局上移、自动文字、窗控点或循环音效。先按新文案和录音确定时段，再选择状态函数。音效绑定输出 cue，冻结子树不冻结声音。

原版依据：公共库中的 branch-and-focus、expand-and-return、counter-slot、diagram-defocus、formula-focus 与 materials-to-results；表面和正文/波形来自用户认可的内容方向。`ExpandReturn` 是单表面的几何展开/返回工具；C06 原版是列表项拆分后合回，精确复用它应读取该版本 ListExpand，不能用单表面工具冒充。准确原版版本从库查询；本适配组不改变 55 条源参考的计数或文件。

复制所需源码到本期再适配，字体和真实音频作为当前依赖登记。检查最长文字、最大尺寸、入场/交接区间、字幕运动包络和连续样片。状态测试与构建验证只证明相应技术行为，新布局仍须实际视觉验收。

## 三种可选组合用法

完整提示词＋逐项底色高亮＋镜头靠近，以及原图选区＋连线＋单处/多处特写的组合，按 [提示词聚焦与图片局部特写](prompt-and-detail-camera.md) 实施。它们是调用方的组合方法，不是本文件新增的导出组件；真实字符范围、ROI、镜头状态与时间仍由本期数据提供。

以下是现有原生能力的组合指导，不是新增导出组件或默认页面模板。由当前内容决定是否使用；字号、位置、颜色、载体、动作方向及时间均由当前合同提供，不继承单期文案、设备或镜头顺序。

### 概念解释

口播正在从术语转向含义时，保留主题对象，用 `SlotReplace` 选择当前问题、定义或例子；调用方按 cue 添加必要的文字揭示与退出。名称、问题、定义只是可能的语义顺序，口播没有的步骤不强加。旧词退出其裁切范围后再让新词进入，检查最长文本和上下段承接；需要读清时稳定停留。

### 保留上下文的重点强调

原场景正确、当前结论需要突出时，将保留内容、调暗层和强调文字分层。强调句按口播进入，结束后移除强调层并接回原场景当前时刻；原视频继续播放或显式定格由本次合同决定，不擅改先前动作。全屏叙事可全屏调暗；只强调一个黑色载体时，蒙版跟随该载体范围。字幕约束只作用于文字等关键前景。

有语义的背景缩小退后可用 `FocusStage`；在已成立的原场景上叠加结论、要求几何不变时使用 `FrostedFocus`。它保留背景/蒙版/前景节点，仅改变背景模糊及覆盖层强度，不自动平移、缩放背景。连续几句共用同一节点，切换前景内容而不卸载蒙版；背景视频继续还是定格由调用方显式决定。用户只要求搬走被挡的小字时，只清除该旧标签并恢复其背后的表面；不擦掉之前的标题和演示。按实际编码帧检查覆盖处颜色和接缝，不假设源白色解码后必为 `#FFFFFF`。

### 文档差异强调

先根据真实新旧内容区分新增、修改和未变部分，再在原文档布局中高亮相应字符或行。`TranscriptSelection` 可处理局部选中；新增/修改状态及字符范围由调用方提供，不能把选中自动解释成新增。文字颜色或下方背景均可表达差异，选一种适合当前风格的方法，不固定浅紫色或黄色。

高亮绘制在固定文字几何的下方或文字颜色层，进入与退出不改变行高、字重和滚动位置。修改只有局部时保留其余文稿；检查高亮的首尾字、滚动裁切和字幕范围，避免把整段都染色导致真正变化消失。

## 固定原场景的毛玻璃聚焦

```tsx
<FrostedFocus
  background={existingScene}
  foreground={currentEmphasis}
  progress={focusProgress}
  tone="light"
  blur={19}
  tintOpacity={0.58}
/>
```

调用方提供定位舞台及由当前帧推导的 0–1 进度；示例数值只展示 API，不是跨期视觉参数。`tone="dark"` 用于暗色覆盖，前景字色由调用方匹配。进度为零时前景仍挂载但不可见，反向 seek 不应遗留上一状态；组件不负责替换文字的动效，也不改动背景子树的时钟。当前实现已通过状态和构建检查，尚不具有独立的用户视觉批准；整合到新片仍检查入场、连续强调和退出。
