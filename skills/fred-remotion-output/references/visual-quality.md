# 已认可质量如何落到新内容

新作先读[DESIGN.md](../DESIGN.md)的默认外观与动作逻辑；本文件处理进一步诊断。历史keep的局部小字、紫面、细边或标题不成为新片默认。

## 按内容选方案

| 语义任务 | 已选来源的可借用关系 | 本期必须重新决定 |
| --- | --- | --- |
| 一个方法拆成多个职责 | 82 方法分支、96 各司其职、原版分支聚焦/展开返回 | 根节点、分支数量、最长文字、出现 cue 与最终焦点 |
| 读提示词或交接笔记 | 94 GlassPrompt/FullPrompt、96 Notes | 完整原文、真实字符范围、跨行矩形、相机目标与阅读时间 |
| 比较生成效果或展示证据 | 94 Comparison/Detail 与不同图片交接 | 实际单图/多图、原图ROI、是否需要建立全貌/局部、同职责几何与主次 |
| 展示产品与实际操作 | 82 协作光标/显示器、93 手机/侧边任务、94 屏幕接管 | 真实媒体、设备内容框、播放入点与连续时钟 |
| 逐项选择和 AI 回答 | 已选列表、Agent steps、prompt send、answer stream、聊天消息 | 实际步骤、查询词、返回内容与出现次序 |
| 突出判断或纠正 | 93 规则聚焦/人物制止、双对象焦点切换 | 当前主语、背景保留范围、手势指向与退场 |

方案是候选。命中更准确的用户指定参考时以指定源为准；所有备选都不合适时根据新稿设计，不为了使用库而生硬套用。

## 文字与真实内容

- 标题、强调、标签、正文按职责设字阶，锁定本片选用的字体文件与字重。MiSans Semibold 600与Medium 500是已有备选，准确参考使用其他字形时按其来源适配；最终看真实加载字形、最长内容和可读性。
- 正文展示本期真实内容；需要交接笔记时保留本片实际相关的目标、进度、保护项、待办等。不能用无信息的栏目名替代应展示的正文，也不为凑齐示例栏目编造内容。
- 先改信息分组与模块宽度，再调整字号；不逐字符硬换行、不拉伸字宽、不把主要内容缩小来迁就装饰。
- 讲全文时确保观众已有全貌，上游已建立可直接承接；聚焦时保留必要上下文。重点字符来自真实文本测量；跨行高亮拆成对应行矩形，重复词按字符索引而不是首次字符串匹配。
- 紫色刷底在文字下方，不能遮字或改变行高；高亮、文档承载和文字共用几何。用户要求该效果时不能替换成单一细下划线。
- 93 期明确允许大字靠左；对齐依据为所属载体、视觉主次和共同基线。左右相关底行看共同视觉基线、组间距离和实际字形粗度；拥挤先改字距/行距和空间。逐项进入检查每项首个可读帧，避免同级白字的后项意外变灰。小模块通常主/辅两档即可，不混四种字阶；不是整期只许两种字号（F08）。
- 完整文档可以先滚完再解释，也可以按讲解滚动定位、聚焦、继续；选择一种清晰阅读路径并核对最后一条实际出现。能一页清楚展示时不强加滚动（F02）。

详见 `skills/fred-remake/references/prompt-and-detail-camera.md`。该文档是实施方法，准确候选源码由新 Skill 查询返回。

## 镜头和交接

- 运镜应服务可辨对象、内容或关系。需要精读的窗口停稳；流程浏览和有效参考片段动作可持续，避免无内容职责的缓慢漂移填时长。
- 相机移动、设备外壳变化与媒体时钟分开控制。设备到全屏时按实际屏幕框同步圆角/裁切/外壳；视频保持连续播放，静态截图无需伪造内部动作。
- 连续细节通常可直接交接；是否回全景由本句责任与节奏决定，避免无理由反复复位。局部蒙版的范围与时机应对应实际重点，不无故改变已认可区域。放大、缩回或弹窗关闭沿同一源时间和界面身份；查中间帧而非只比终态，优先去除无职责推拉或突兀停止。
- 蒙版按真实职责决定范围。整场压暗覆盖整画布；局部强调只覆盖对应载体。白色胶囊或文档去描边时保留承载面，不让文字突然落在纯背景上。
- 前景、蒙版和背景保持稳定节点，不能因换文字反复卸载导致闪一下。字幕区只约束关键前景；全屏转场遮罩不跟着缩成上部区域。
- 设备屏幕接管与局部裁切详见 `skills/fred-remake/references/device-camera-rhythm.md`；固定背景的毛玻璃强调可参考现有 ContentMotion，但不冒称它与某个原版一模一样。
- 前景强调与设备运镜分别选择：只在原电脑上叠加重点时保持背景 bbox/scale；不要因为调用聚焦组件而默认把电脑推高（F07）。
- 同轮同职责的窗口保持几何协调；跨组可继续复用成熟布局，也可按内容换载体。同系列运动速度协调，精读停留与总览浏览分别安排（F01/F04）。
- 需要连续表达时从真实尾态延展；直接切换或简洁换字也可按语义成立。录屏、话题和稿件责任共同决定分组，不为了转场机械刷屏，也不强求每个边界复杂动效（F10/F18）。

## 关系线、搜索、数值和人物

| 对象 | 要检查的实际状态 |
| --- | --- |
| 实际使用的关系线 | 检查进度零、进入、收回和下游状态；非本意的线帽/残点可用条件挂载等方式处理，保留有语义的节点，不为关系场景强加线 |
| 搜索 | 输入框、明确查询、结果与选中能被辨认；结果运动后下方不突然留大空场 |
| 数值或余量 | 实际使用的数字、单位、标签及图形与同一数据和cue一致；不强加条形图，示意值不冒充实测 |
| 人物 | 使用已选动作的有效帧段；手势/视线与被指对象一致，出现位置分散；不用无效头帧强行从零播放 |
| 角标 | 解释动画按既有brand-corner规范；源视频作为主内容播放时关闭新增右上角角标，混合场景检查实际显隐窗口；核对准确资产、局部底色和固定画布几何，不跟设备镜头放大 |

人物 Alpha 是媒体依赖，不是可编辑骨骼。不要把排除的人物带字卡片与保留的透明人物动作混为一类。

## 代表镜头到完整视频的检查

布局静帧覆盖最长文字、最大特写、跨行高亮和首尾状态；正常速度播放覆盖完整语义窗口；原生帧率密查显示/隐藏、换词、分块边界和接缝。单张首尾图不能证明中间没有黑点、重叠或空帧。

镜头组内保持字体、同职责对齐和材质质量；跨组按语义决定复用或换形式。没有要求用齐黑底、白底、人物、手机或每个组件。过长静止要看口播是否继续引入信息；稳定阅读不能仅因“静止”被判失败。
