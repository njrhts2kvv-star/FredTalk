# Library 原片的镜头组织方法

当 Fred 要求参考 Library 同学的镜头变化、录屏拆层或文字呈现时读本文件。这里整理的是本机 **25 段 Library 原片对应区间**的抽帧时序、组件动作说明和视觉库条目，涵盖旧库 B/C/R/T/W 与新 10 期 N 片段。它能支持主要对象的进出顺序判断；不是全部 Library 视频的普遍规律，也不代表已按正常速度完整审看缓动、声音与全片节奏。当前 Fred 复刻的改编文字、媒体与配色不作为 Library 原片特征。

## 从内容决定镜头动作

先写清本段要让观众理解什么变化、主对象从哪里来、变化后去哪里，再选组件。可观察的共同关系是：**来源可见 → 重点改变尺度或层级 → 观看关系变化 → 接回上下文或进入下一层**。这是选型线索，不是每段都必须套用的转场顺序。比较关系可以并列停稳，关键操作可以靠近，结论也可以直接稳定呈现。

| 观看任务 | 原片中可观察的动作链 | 查看片段 |
| --- | --- | --- |
| 用同一对象交接镜头 | 产品名逐步写出并推近，越过画面接日历窗口；手机内视频被提成独立横窗；前景结果图反向缩回聊天记录原位置。交接时要认得出对象的来源与去向。 | R001、B059、N046 |
| 改变容器与观看关系 | 桌面横窗交给手机，再并列头像与动作；主视频和右下原片小窗变成两窗等大对照，素材身份保持不变。 | R014、N023 |
| 从真实画面提取前景 | 页面输入框提到前景，背景变暗，发送后输入框回到页面并出现结果；已有结构失焦，短句接管焦点。 | N040、B064、C006 |
| 用文字交代语序与层级 | 新问题来时旧句斜转、上移、变灰；聊天气泡整体上卷接新消息；圆点长成胶囊显出关键词，再扩成黑场；同一窗口更新版本数字与箭头。 | N002、W04、B002、R004 |
| 单案例扩成作品群 | 六格作品墙收成标题，再展开竖图并接回网站；多列竖图连续滚动替换；一行影片带扩成上下三行反向流动的作品墙。 | R033、B041、N011 |
| 从全貌引出重点和结论 | 提示词全貌失焦，参数词凸显，再回全貌；一个起点长出多列矩阵；滚动证据页缩小侧移，右侧清单逐项变实。 | B009、C002、N054 |

编号用于定位动作，不等于选用整条成片或获得新内容的视觉认可。用[新 10 期分类索引](library-new10-confirmed.md)与[旧库 81 条索引](library-legacy81-confirmed.md)定位当前复刻；动手前回看对应 **Library 原片区间**，核对对象、动作顺序与适用范围，不拿 Fred 改编成片反推原片做法。旧库原片准确路径与区间以项目 `skills/fred-remotion-output/assets/reference-code/library-remakes-legacy81-20260929/catalog.json` 各条 `reference` 为准。新 10 期使用当次提供的 Library 原片或独立片段；分类索引里的 `videos/` 是当前复刻成片，不充当原片证据。

## 带入当前场景

在已有 Manifest 的当前场景和逐段建议里写明：口播时间与实际素材来源、主对象、入镜前状态、进入/聚焦/稳定阅读/退出动作、前景与背景关系、文字如何按语序出现、下一镜承接、参考编号及本期与参考不同之处。选动作时保护已确认的本期内容和素材身份；从录屏里抽出输入框、人物、图片或视频，要让观众看懂它来自哪里，必要时检查遮罩边缘、阴影、背景压暗或失焦。文字的滚动、换焦、逐项填入服务句意；光泽或闪烁只有确实需要强调时才用，不把 Fred 举的效果例子写成 Library 的固定公式。

录屏在后景的处理由内容决定：`N054` 的证据页继续滚动。需要继续播放时，前后层对齐同一媒体时间点，检查不跳帧、不意外循环，也不伪造真实操作；暂停或退场时记录为什么这样更清楚。具体实现依照[媒体与蒙版](media-and-overlays.md)，文字局部动作依照[文字呈现](text-presentation.md)，不要另建一套媒体时钟规则。

用本期真实文字、录音和媒体做现有流程里的关键帧与可播放短段，检查最长文字、遮罩边缘、字幕避让、镜头交接和正常速度下的可读停留；整片按[制作默认值](production-defaults.md)继续检查连续播放。抽帧与组件编号只证明参考动作可定位，不能代替新片的动态审看或用户对当前版本的确认。
