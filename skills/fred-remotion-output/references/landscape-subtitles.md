# 横版得意黑字幕模块

适用于 FredTalk 16:9 独立讲解视频。第 100 期的 5 秒得意黑样片是样式与几何基线；用户本轮明确要求把字体、字幕位置和黑色包裹模块保存为后续可调用能力。它不代表第 100 期整片字幕已获视觉认可，也不覆盖竖版 PingFang 字幕、明确无烧录字幕的任务或当前另有样式要求。

## 直接使用

- 项目实体：`assets/subtitle-smiley/SmileySubtitle.tsx`、`SmileySans-Oblique.ttf`、`LICENSE`。官方仓库为 `https://github.com/atelier-anchor/smiley-sans`；字体取自 v2.0.1 官方发布包。不要依赖 Downloads、历史 episode、全局 Skill 镜像或系统已安装字体。
- 新工程复制组件到本期 `src/`，字体复制到本期 `public/fonts/SmileySans-Oblique.ttf`。组件使用 `FontFace` 和 Remotion `delayRender` 等字体加载完成后再出帧。
- 将字幕放在场景与媒体层之上、同一 `1920×1080` 逻辑画布内，在整片组合处调用；角标另按当前场景的媒体播放窗口显隐，不能因为字幕放在全局就把角标也全程显示。先决定是否已有烧录字幕，避免叠双层；字幕 cue 使用最终音轨和最新 SRT 的真实全片秒数，`startSeconds` 包含、`endSeconds` 不包含。若字幕组件处于 `Sequence` 内，传入全片 `timeSeconds`。

```tsx
import {SmileySubtitle, type SubtitleCue} from './SmileySubtitle';

const subtitles: SubtitleCue[] = [
  {startSeconds: 1.2, endSeconds: 3.0, text: '但我给大家泼下冷水'},
];

// 放在 1920×1080 逻辑画布的场景层和角标之后。
<SmileySubtitle cues={subtitles} timeSeconds={filmTimeSeconds} />
```

## 第 100 期样片基线

| 项目 | 3840×2160 输出 | 1920×1080 逻辑画布 |
| --- | ---: | ---: |
| 字号 | 95 px | 47.5 px |
| 黑框最小高 | 203 px | 101.5 px |
| 框圆角 | 34 px | 17 px |
| 底边距 | 51 px | 25.5 px |

黑底 `#000`、白字 `#fff`、水平居中；框宽随文字内容自然伸缩。参考首句在 4K 的框约 `x=1532, y=1906, w=779, h=203`，截图对照框边界误差约 1 px。字号、位置、框尺寸是第 100 期样片的实测基线，新期按真实字幕长度、不同视频规格和用户要求适配。长句按口播语义拆 cue；确实需要双行时检查盒高向上扩展，保持底边距，不能溢出黑框或贴到画面边缘。组件默认最大宽 1720 个逻辑像素，可按当前画面调整。

## 制作时读取和保存

新一期在根`subtitles`保存enabled、实际sourcePath/sourceSha256、全片cues和当前几何；关键帧前带入真实字幕。`scene.py`只将与本场景全局窗口相交的cue带入资料包。规划允许字幕源尚待导入，启用字幕的代表门前必须有真实cue数组；有SRT路径时核对sourceSha256，不因同名文件沿用旧画面认可。

## 字幕文字与指定称谓

烧录前核对产品名、同音错字与明确指定称谓，并保存到当前`designContract`的术语约定。豆包工作的拟人代词使用「她」；按上下文查每条cue，不能把指代文件、项目、设备或其他人物的「他/它」一起替换。用户指定准确文字后，用最新字幕和实际输出再核对，声音中同音的人称不需要重录。

字幕样式与正文大字是两套职责：正文换指定字体不自动替换得意黑字幕。纯文字修正保持既有cue时序、框体和画面；外挂字幕可只替换字幕轨，烧录字幕需要局部重渲实际出现的帧，再按[局部合并](render-and-delivery.md#烧录字幕与局部合并)拼回完整视频。核对新文字真实盒宽、首尾显示帧与受影响接缝。

## 与动画前景避让

规划每个字幕 cue 的实际出现窗口与最大盒宽；把胶囊、关键卡片、关系节点、读数、提示词焦点和设备内需要看清的操作区域视为关键前景。Remotion 动画中先调整这些前景的布局或运动路径，让它们在字幕显示期间与字幕盒保持可读间隔；不要仅检查一张定格，也不要默认把字幕挪来挪去。前景确实需要靠近底部时，结合语义停顿、出现时序和字幕分句做局部协调，并复核前后场景的首尾态。全屏播放的录屏或视频可以延伸到画面底部，重点核对其承担信息的 UI/文字没有被字幕遮住。

代表镜头和正式文件分别检查：最长字幕、双行或最大框宽、胶囊/卡片整个进入与退出运动包络、相邻段接缝、角标、字幕与口播同步。记录实际检查时间点和当前文件版本；技术解码通过不等于这些局部可见性检查通过。
