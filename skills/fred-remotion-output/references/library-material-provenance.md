# 视觉库素材来源与替换

视觉库的动作参考、源码实现和媒体素材是三件不同的事。使用本地文件不代表文件里的图片、录屏或影片属于当前创作者；换名称或改目录也不改变素材来源。

替换媒体时，保留已认可组件的构图、对象关系、动作、原生帧率和时间映射。为每个载体明确素材职责：人物槽放人物，设备槽保留设备外框，界面放进屏幕，遮罩和粉笔纹理保留透明度、前景颜色及对应路径。逐帧文件属于同一素材序列时，按载体/目录绑定稳定素材，不能按每个帧文件名随机选择图片。

只对实际受影响的预览、封面、核心帧和源码进行更新。新视频必须完整解码，并检查真实画面、媒体时钟、裁切、纹理、交接与连续播放。新素材、旧动作认可和当前内部验收分别记录；不要把继承的取舍标成用户已看过新视频。

当前授权输出1080p时，可生成匹配尺寸的渲染副本，保留原始素材和原生帧率/帧数，记录来源hash、缩放和编码参数，并对照实际输出。渲染副本不替代原始来源证据，也不更改正式制作的默认规格。

分发前核对当前媒体清单和素材包的hash一致。隔离的旧输入不能被下载器恢复；旧预览缓存不能继续指向被替换的像素。源码提交、媒体包、前端投影与网站分别核验，全部更新后才报告同步完成。用户授权使用媒体不自动授予下游公开版权许可；必要的许可证和权利声明保留。
