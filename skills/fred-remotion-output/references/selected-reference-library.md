## 新视频的最短调用路径

1. 用当前场景小抄确定 `scene-type`，写清要观众理解的关系。
2. `references.py --scene-type relationship --query 分支 --limit 3` 查询少量适用参考。`--scene-type` 实际筛选候选；主类型在候选数量限制之前生效。
3. 看返回的准确视频和源码符号，保住 `preserve` 中的动作关系；按本段文字、素材和录音适配。不要将几张静态图、一个同名函数当成完整动作一致的证据。
4. 从 `sourceBundle/entryPoint/publicDir/dependencyManifest` 找到完整依赖。先复制到当前场景的工程再改；选中的代码与示例图片/音频不能混成新一期的真实素材。

```bash
python3 skills/fred-remotion-output/scripts/references.py --scene-type metric-change --query 百分比 --limit 3
python3 skills/fred-remotion-output/scripts/references.py --id library-fred-remake-060
python3 skills/fred-remotion-output/scripts/references.py --collection library-fred-20260913 --query 031 --limit 3
```

纯编号查询（如 `004`、`4`、`#004`）精确匹配原编号与合并别名，不匹配其他记录ID里的数字。不同集合可能重号，按本批反馈查找时加 `--collection library-fred-20260913`，也会找到沿用旧库的主代表。复制依赖时以查询返回的 `sourceBundle`、实际源码文件及锁文件为准。

准确 ID 查询可能返回已合并或排除的历史记录。这只是审计入口：有 `canonicalId` 时继续查询该 ID；`selectionDisposition=user-rejected` 则不采用。普通查询默认只取 keep 且没有 canonicalId 的主代表。旧编号作为别名，不能把合并记录重新当成额外可选项。
