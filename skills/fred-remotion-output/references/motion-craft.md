# 动效手法（让动作“顺”的具体写法）

本文总结 63 条已认可参数组件（fred-native-16、fred-wave2-42）里实际用到、Fred 评价“动效非常好”的写法。

- DESIGN.md 第 2.4 节规定**用哪条曲线、多长时间**；本文讲**怎么写出来**。
- 新做组件、二创旧组件时都按本文；换模型做也照这里的写法。
- 代码例子取自真实组件，组件位置在 `assets/reference-code/fred-wave2-42-20261012/source/src/components/`。

## 0. 总原则：一切由帧号算出来

- **只用 React + 内联 CSS。每一帧的样子都由 `t = 帧号 / fps` 算出来。**
  - 不用 CSS `transition`、`@keyframes`，也不用 Remotion 的 `spring()` / `interpolate()` 默认写法。
  - 原因：渲染是逐帧截图，靠浏览器时钟的动画会跳帧、不确定；自己算的进度每帧可复现，云端和本地画面一致。
- **进度函数只用 kit 的**：
  - `p()`：主曲线，ease-out，用于进入和落定；
  - `q()`：smoothstep，用于搬移、缩放、蒙版；
  - `wipe()`：章节擦出；
  - `springAt()`：一次轻微回弹；
  - `quintic()`：相机，两端零速度。

  63 条里 `p()` 用了 201 处、`q()` 76 处、`springAt()` 24 处、`quintic()` 19 处；`spring()`、`interpolate()`、`@keyframes` 都是 0 处。
- **动画属性只改这三类**：`transform`（translate / scale / rotate）、`opacity`、`clipPath`，外加少量 `filter: blur()`。不靠改 `width`/`left` 去“挤”布局，几何由组件自己算好，再用 `abs(box)` 绝对定位。
- **SVG 只用在必须画线的地方**：流程线、箭头、对勾、光标。用 `<path>` 加 `strokeDasharray` / `strokeDashoffset` 画出线条。63 条里只有 7 条用到 SVG。

## 1. 先算终态版式，再让东西“走到”终态

**写法**：每条组件开头先按真实内容算好终态几何。

- 字号：`min(上限, 可用宽 / textWidth(文字, 1))`；
- 行数、列宽、居中位置；
- 再算每个对象的起始框。

动画就是在“起始框 → 终态框”之间插值：`between(fromBox, toBox, 进度)`，或 `mix(a, b, 进度)`。

**为什么顺**：对象从哪里来、到哪里去一开始就定了，中途不会跳位；换长文案时，终态自动重排，动作仍然成立。

```tsx
const pill = between(fromBox, toBox, lift);           // T17a：配置行原位“拎出”成胶囊
const size = Math.min(84, 1500 / textWidth(text, 1)); // 按真实文字算字号
```

## 2. 过冲后回落：让“落定”有分量

**写法**：圆点长成圆、胶囊横向展开时，先冲过目标一点（3%–5.5%），再在 0.14–0.3 秒内回落。这个比例来自 L81-T03 的实测轨迹。

```tsx
// T01f / T01e / T12d 共用写法：主曲线先到 1+amount，再用 smoothstep 回落到 1
const overshoot = (t: number, a: number, rise: number, settle: number, amount: number) =>
  p(t, a, a + rise) * (1 + amount) - amount * q(t, a + rise, a + rise + settle);
const open = overshoot(t, at, 0.55, 0.3, 0.055);    // 胶囊宽度过冲 5.5%
```

**边界**：只用在建立和落定的那一下。回弹用 `springAt()`，一次就停，不能让东西一直弹。**入场默认不过冲**（Fred 10-14，119 期嫌“进来之后抖动了一下”）：成片里的入场和胶囊落定用无过冲的 `settle()`（kit v4 的 `theme.ts`），过冲只在 Fred 明确要“砸下来”的效果时用。

## 3. 同一个进度驱动多个属性：动作是“一个动作”

**写法**：一个动作里的位移、缩放、透明度、圆角、字号，都从同一个进度变量算出来，不要各算各的时间。

```tsx
// T12b：方块让到左边和胶囊抽出共用同一进度 shift，胶囊右端单调走到终点，不会先冲出画面
const shift = p(t, outAt, outAt + 0.6);
const tileX = mix(960 - tileW / 2, 960 - groupW / 2, shift);
const pillLeft = tileX + tileW / 2;   // 胶囊从方块中心开始（藏在方块后），随 shift 一起展开
```

**为什么顺**：多个属性同时开始、同时结束，看起来是同一个物体在动。分开定时容易出现“外壳先到、字后到”的拖沓感。

## 4. 对象连续：变形，不要“消失再出现”

**写法**：
- 圆点 → 圆 → 胶囊 → 徽标，都是同一个 div 改尺寸和圆角；圆角取 `min(w, h) / 2` 的变化。
- 材料到结论时，从原位“拎出”（T17a、T09b），或从原位放大（T09e、RC04 写法）。
- 汇聚时，几项缩小、移到中心，结果胶囊从那一叠里长出来（T02e）。

**为什么顺**：观众的眼睛一直跟着同一个对象，能看懂“它变成了什么”。这正是 DESIGN.md 第 3 节“用关系组织动作”的代码落地。

## 5. 裁切擦出：用 `clipPath` 代替淡入

**写法**：胶囊、标签、白条、滑杆，用 `clipPath: inset(...)` 从一侧擦出。可以同时加 20–30px 的位移，有“推出来”的感觉。

```tsx
// 横向擦出（T02e、T04d，带圆角）
clipPath: `inset(0 ${100 * (1 - e)}% 0 0 round ${h / 2}px)`
// 自下而上打开（T12e 章节白条）
clipPath: `inset(${100 * (1 - open)}% 0 0 0)`
// 滑杆对比（T05a）：同一位置叠两张图，上层只露出滑杆左边
clipPath: `inset(0 ${BOX.w - lineX}px 0 0)`
```

**为什么好看**：擦出时轮廓清楚、方向明确，比整块半透明淡入更利落，也不会出现半透明叠字。

## 6. 文字动画三件套

- **逐字打出不跳位**：整句先按终态排好，还没打到的字设成透明占位（`color: 'transparent'`），光标用零宽锚点。这样打字时整行不会左右挪（T01e、T01g）。
- **两层文字做反色**：同一套文字画两层，一层是白画布上的黑字，另一层放在白条或黑胶囊里、用 `clipPath` 跟着容器走。容器走到哪里，哪里就反色（T12e 白条、T12g 滑块）。
- **划掉要干净**：先把字退灰，再让一条墨线沿字的中线、按宽度生长，不叠第二层字（T05c、T06b）。

## 7. 景深层次：退后 = 缩小 + 失焦 + 蒙版

**写法**：
- 材料退后：`scale(0.92–0.96)` + `blur(12–19px)` + 白蒙版（`.74–.86`）或黑蒙版（`.5–.6`），三者用同一进度；
- 前景浮起：用 `S.shadow` 或 `S.capsuleShadow`，再加 1%–10% 的放大。
- `Handoff exit="recede"` 就是这套写法的通用版。

**边界**：
- 蒙版和失焦只作用在材料层，不作用在重点文字和角标上；
- 表格、列表这类还要读的退后内容，失焦不超过 4px，或者不失焦（T15b 返修经验）。

## 8. 相机：推近读清、停稳、再走

**写法**：
- 用 `quintic()` 算推近进度，再用 `cameraTransform(焦点x, 焦点y, 倍数, 进度)` 变换整组内容；
- 每次移动约 0.6 秒，停稳读 0.85–1.65 秒；
- 推近倍数按“目标整行都在画面内”反算（T05c：`zoom = min(1.32, 1760 / 目标宽)`）。

**边界**：不全程慢漂；读完回全貌或交给下一段。

## 9. 依次出现：按口播，不机械等距

**写法**：
- 每个主动作的时间都用 `cueAt(c.cues, i, 默认秒)` 取；有口播就按口播，没有就用默认节奏；
- 默认节奏的项间隔取 0.5–1.2 秒，不要完全等距；
- 同组小件可以错开 0.045–0.075 秒（107 证据卡、VideoWall 写法），像一叠卡片顺序摊开（T05f）。

## 10. 声音跟主动作

- 一个主动作一声，挂在动作开始或落定的那一帧：`<Sfx name="pop" at={at} />`。
- 打字声只覆盖打字区间，滚动声只覆盖数字实际滚动的区间。
- 对应关系见 DESIGN.md 第 2.6 节。

## 11. 用真实像素做前景

**写法**：
- 需要“填入、勾选、开通”这类状态变化时，不画假 UI，而是在真实截图上叠干净的前景层：提起的输入条、点击环、状态胶囊、勾选圈（T09c、T09b、T09f）。
- 要强调截图里某一块时，把那块真实像素复制出来提起或放大（T18c、T08d），坐标用源图像素作 props。

## 自查时专门看动效的几帧

`component_kit.py sheet` 默认取的帧之外，动作关键处要用 `--frames` 加密看，每 2–4 帧一张。重点看：

- 过冲最大的那一帧；
- 两个对象交接的中间帧；
- 文字刚开始出现的第一帧（不能意外变灰、叠字）；
- 退场最后几帧（不能有残留）。
