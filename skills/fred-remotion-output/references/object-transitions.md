# 对象之间的过渡与注意力交接

用于安排“上一项如何让位、当前重点如何进入、下一项如何接走”。既可用于场景内部，也可连接两个场景。先读当前类型小抄，需要时再加 `object-transition`，不用搬用参考片的完整构图。

Fred 本次明确喜欢胶囊交替缩放、上下左右移动与大小变化。原话绑定在 `transition-patterns.json` 的 evidence；动作例子仍从现有keep来源取用，排除项不回流。这里只增加局部动作索引，不新增成片选择台账。

## 先决定交接关系

一句话写清：**旧对象退到哪里、谁接管注意力、还有什么必须留在画面里。**

- 继续讲同一主题的下一点：旧项缩小留作上下文，新项在阅读中心放大。
- 给当前主体补充说明：主体侧移，说明进入空位，结束后主体回中。
- 从环境进入细节：保留对象身份，围绕实际阅读区域推近，按内容需要回到全貌。
- 从多个例子收束到结论：对象聚拢后归并；并列比较则向两边展开。
- 开始下一组内容：旧对象与新对象在一个明确的运动窗口内交接。

配色延续Fred黑白为主、紫色点缀。复用单位是对象关系和动作顺序；上下、左右属于方向变体，载体可换图卡、窗口或设备，按实际文字和几何适配。

## 交替缩放如何迁移

以T01为例，定义A的阅读位置和退让位置、B的阅读位置。A缩小并移到停靠点，B在空出的阅读区建立；文字、边框和承载尺寸协调改变。原例第一轮A约在0.60–1.15s退让，B约在0.95–1.45s放大，小重叠让交接连续；这是参考时间，不是新视频的固定节奏。

单层、左上角为变换原点时，可先插值屏幕锚点和倍率，再反推位置：

```text
anchor(t) = mix(readingAnchor, parkingAnchor, progressOut)
scale(t)  = mix(readingScale, parkedScale, progressOut)
x(t) = anchorX(t) - localAnchorX * scale(t)
y(t) = anchorY(t) - localAnchorY * scale(t)
```

新项用自己的进入进度，绑定下一句口播，稳定阅读段单独保留。上下改左右时交换运动轴与停靠点，文字不镜像；按最终bbox检查两段长文在中间帧是否重叠。端点由本期内容决定，不固定沿用原字号、坐标和缩小比例。

实现可整组等比scale，也可分别插值宽高、字号和位置。T01原例属于后者；只缩小黑色外壳而不处理文字，会破坏主次关系。

## 取代码前核对边界

- 保存的是动作参考、准确源码及依赖，不是10个统一参数接口。先复制具体函数及依赖的对象/插值工具到本期工程，再按需要形成参数。
- `batch1.tsx` 的 `p(t, start, end)` 第三个参数是结束时间；`batch2/3.tsx` 的 `p(t, start, duration)` 第三个参数是时长，缓动也不同。不能只复制调用再换同名helper。
- `FredMotion` 用帧/FPS换算秒，再由对应batch处理timeScale和cue；迁移时只换算一次。阅读时间不靠持续慢移填满。
- T02/T05主要是平移；T04只提供覆盖端，T08终态窗口尚无新正文。新片须补实际下游内容并核对接缝。
- T07包含阈值触发的正文失焦；T10用同一静态素材的两个显示节点，存在复制展示阶段。需要平滑失焦或像素连续的视频接管时，按具体源代码补足并检查。
- 新长文字、不同图片比例和真实视频时钟要在本期检查。实拍/UI图层仍是素材，不变成原生矢量内容。

完整设备接管几何沿用 `skills/fred-remake/references/device-camera-rhythm.md`；这里补准确动作例子，不复制另一套设备合同。

## 连续轨迹与同载体交接

- 路过锚点不等于停靠点。连续移动若每一小段都重新使用首尾速度为零的缓动，会产生连续启停；按需要选择单段曲线或位置与速度协调的分段轨迹。真正需要阅读、强调或碰撞反应时可以停顿，不强制所有轨迹C1或恒速。
- 同一载体接下一句时，先核对外壳是否已建立，再决定只替换文字、扩容或让位。不要让 scene wipe、旧场 Freeze 与组件自身入场重复控制同一个外壳；检查旧句退出与新句首个可读帧的接力，避免一帧消失或两层阴影重复。
- 尺寸变化与新内容有依赖时，以真实 cue 同步空间和内容：已有首行保持可读，扩出的区域及时接入补充文字。文字不因外壳拉宽而非等比变形；有目的的空壳展开与无信息等待分开判断。
- 固定多项排布按讲到的对象突出即可。层级在突出区间保持稳定，下一重点接管后再交回，不把连续进度取整为频繁变化的 z-index。需要恢复全貌时保留同一对象和媒体时钟。

在完整运动中看锚点两侧、显隐边界、扩容与文字接入、缩放中心和阴影；异常用实际输出定位，不只比较端点。详细触发与阅读检查见[制作默认值](production-defaults.md#将流畅跟口播落实到可观察状态)。

## 在现有分镜里落实

在相关 `motionEvents` 记录 `transitionRef`、`referenceId`、参考片段区间，以及本期谁退让、谁进入、cue和保留关系；`sceneGuide.applications`记录决定与检查。只为实际使用的过渡填写，不要求每镜强加动作。

检查开始、主要中间态、最大缩放/相交点、结束和下一帧：对象身份、旧文字退出、重复节点、意外空场及字幕遮挡。阅读时停稳；跨段另用 `scene.py --stage joining` 核对。按内容选择方向和动作，不把十类参考排成固定套餐。
