# 组件复用能力

以当前数据库的 `reusability` 字段为准，不凭文件名判断能力。

| 类型 | 可直接使用的范围 | 改编前核对 |
|---|---|---|
| 完整参数组件 | 源码明确公开的 props 与受支持的取值范围 | 文案长度、对象数量、媒体比例、时序输入 |
| 部分参数化场景 | 已显式暴露的参数 | 尚未参数化的文字、位置、数量、注册时长 |
| 准确场景快照 | 该场景现有构图和动作逻辑 | 数据与布局耦合、固定资产、缺失输入、进入和退出状态 |
| 画面参考 | 参考片段所表达的视觉关系 | 是否真的存在可调用实现，不能把视频本身说成组件 API |

通过 `python3 scripts/catalog.py --id <编号> --full` 查看准确源码、工程与当前媒体状态。源码文件会在 `sourceFiles` 中列出，工程位于 `implementation.projects`。

先选内容职责，再按源码真实接口适配。不要给旧场景套一层 props 就声称它能接受任意内容。新内容至少检查首个可读状态、最长文本、运动全过程、出口和接缝。

安装步骤见[组件库](library.md)与[依赖说明](components-and-dependencies.md)。不依赖私人历史工程。
