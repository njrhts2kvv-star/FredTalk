## 后续制作

1. 写新稿时，这四句不进入Fred要录的正文。制作备注可标“复用固定过渡配音，约6秒，画面使用本期新动画，勿录制”；纯正文交付把备注放正文之外。完整视频预算另计这段，人的录音时长不包含素材。已有锁定稿／录音不因默认更新自动删词。
2. 在同一Manifest安排一次配音，优先开场结果／案例后或主体讲解前的自然断点。若本期已含相同配音或Fred当次略过，不重复加入；位置不固定为109期的镜号或秒数。
3. 音频来源从manifest.voice查询并绑定当前纯配音的实际路径/hash，不能硬编码旧voice.wav；先核纯旁白与SFX混音职责，字幕相同不代表声源相同。画面另绑定当期新动画及其来源、时长和要求；缺当期动画时列为待提供，不回退旧动画。Fred授权助手选择／制作新画面时，沿用现有组件与制作流程，不把固定配音理解为原创授权。
4. 基础混音只加入一次当前纯配音，使用manifest的真实采样时钟（当前5.540秒），不写死旧6.016秒。新动画若已带相同配音，选一份进入混音，保留需要的其他源声／音效。按当期帧率与新画面计算段长，必要时只补尾静音用于整帧对齐；不锁死旧362帧／832采样，不改变配音语速。最终完整混音编码一次，不能直接拼多段AAC。
5. 新动画按当期要求对齐这段配音，字幕样式、构图、中间动作和前后交接都按当期画面处理，不继承旧烧录字幕或旧视频边界。音频时码可加新全局起点供字幕核对；同文字幕只显示一层。
6. 插入后按实际段长同步后续cue、媒体窗口、音效、BGM静音区间和源坐标映射，保持原录音源时钟，不回写原稿／原音或伪造ASR。此配音属于讲解，BGM按[背景音乐](background-music.md)持续，整片只混一次。

这是Fred个人品牌配音的默认；不自动给其他使用者的视频插入Fred推广。旧动画与已完成成片仅保留历史身份，此规则不追溯改动它们。
