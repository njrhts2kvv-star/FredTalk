# 维护

每次变更维护当前仓库中的唯一事实源：Skill 规则、组件数据库、源码和素材清单。只沉淀可复用的判断、触发条件和检查边界；单次内容、人物来源和私人项目经过不写入通用制作指令。

新增组件时登记稳定 ID、用途、源码工程、实际接口、预览区间与资产安全状态。先验证文件与调用，再审看画面。准确快照、参数化接口和新内容批准分别记录。

素材更换后重新计算哈希并检查封面、音轨和画面隐私。旧批准不自动继承给变更后的内容。禁止将 `.local` 意见、私人录音、凭证和历史 Git 仓库打入分发包。

文档修改后检查链接与实际命令，运行相关测试和构建。公開发布还需要完成仓库中的隐私及权利检查清单。
