# 内容对象、表面与动作的选择

用于讲解视频中的文稿、音频、内容舞台、图标或重复卡片返修。运动参考从项目内已认可风格库查询；当前逐字稿、用户点名范围和已认可外观优先。规则用于选择具体表达，不把所有主题改成同一套组件。

## 先决定观众要认出什么

| 内容职责 | 可见对象与内部变化 | 避免的替代 |
| --- | --- | --- |
| 逐字稿 | 连贯正文，常规到中等字重；局部选中、光标或当前句变化 | 三横杠、两句宣传标题、整套转写软件外壳 |
| 录音定位 | 有起伏的波形、选区和播放头；刻度按同一时间比例 | 装饰声波、随机时间数字、重复按钮 |
| 画面怎么动 | 当前内容真的揭示、推近、让位或通过遮罩交接 | 只有“文字/镜头/转场”的通用 icon |
| 提示词 | 与当前演示相符的正文，密度与可见面积匹配 | 乱字、灰横杠或为了填满而新增观点 |
| 可修改的结果 | 同一内容中可见的参数/状态变化；承诺代码时提供准确代码或明确的受控预览 | 无关勾选状态和三张“成功”卡 |
| 实际功能或结果证据 | 真实截图、录屏、文件或数据 | 用生成假 UI 证明真实操作 |

缩略态先让人认出内容类别，展开态再呈现细节。按可见主体尺寸平衡文稿、波形和媒体，不把所有 1:1 图片机械设为同宽。小尺寸正文不必每个字都读完；标题、关键句和证据数字必须能读清。

关系线只在确实表示分支、流程、对应关系时使用。给胶囊加下划线、在卡片旁放短黑线不能证明“前后串起来”。连接应有明确两端和方向；跨场连续性通过同一对象的变化呈现。

## 用哪种制作方式

- 可确定的正文、选区、指针、排版、几何和遮罩：Remotion 原生分层；有准确源码先复用。
- 需要探索镜头、空间与形状衔接：H3 生成动态参考，随后按实际结果还原。
- 人物表演、复杂材质和插画确实承担内容：使用已有媒体或按授权生成独立资产，Remotion 合成。不默认把所有名词换成 3D icon。
- 真实操作与结果证明：真实素材。生成图可作视觉草案，不能替代证据。

## 表面与内部内容分层

背景 → 前景布局 → 载体位置/尺寸 → 表面与阴影 → 内部裁切 → 正文/波形/媒体。全屏过渡独立覆盖画布。

“无描边白模块”指白色填充、合理圆角、内边距与轻阴影，没有 border/stroke，也没有借 box-shadow 的 spread 模拟边线。不是把白色承载一起删掉。只有表面本身按设计被遮挡时才裁表面；文字滚动和揭示通常只裁内部内容。

黑白承担主要层级，颜色按职责使用：品牌保留来源色，选区/指针用功能色，少量重点可用当前指定强调色。不能把所有模块染紫，也不把真实彩色照片、角色或功能选区强制黑白。次级波形和局部阴影可使用灰度；用户要求纯黑白时相应收紧，不新增大面积灰底或灰色主结论。

字幕避让约束关键前景的整个运动包络，比例来自本任务。背景、调暗蒙版和整屏转场仍铺满画幅；不能在底部留下永久白带。

## 返修先定位是哪一层

| 反馈 | 先检查 | 保留 |
| --- | --- | --- |
| 卡片太多 | 内容重复、嵌套、布局、入场仪式分别诊断 | 有职责的分组和白色承载 |
| 右边太空 | 右侧内容职责、实际主体尺寸和左右分量 | 有意义留白；不用无关物件填空 |
| 动作慢 | 空等、重复建立、过长位移 | 关键句阅读和结果停留 |
| 末段太快 | 内部演示是否被压缩、多次无必要换结果 | 一次清楚的结果变化与稳定终态 |
| 一帧少了底框 | 父级 clipPath、表面/阴影裁切、旧尾帧依赖 | 原运动与内容；不能补黑边掩盖 |

当前合同只保留最终有效字段；被替代要求进入修订历史，不继续在旧描述后堆加“Revision”。编译前核对同一对象的 fill、stroke、shadow、clipScope、textRole、colorRole，不能同时要求灰描边和无描边、必须道具和移除道具。
