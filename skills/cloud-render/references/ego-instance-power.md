# 用 Ego Lite 启动和关闭云实例

## 适用与授权

Fred 已授权云端渲染采用自动电源生命周期：开始前发现已授权实例未运行就直接启动，交付与校验完成且远端无活动任务后默认关机，不重复索要同一授权。优先使用官方 API；API 不可用或结果不确定时，通过 Ego Lite 复用现有登录态操作并完成平台状态验收。此授权不包含删除、释放实例、购买或扩容；当前明确指令优先，当次要求保持开机时不执行默认关机。

开始前读当前 `ego-browser/SKILL.md`，使用 `ego-browser nodejs`，不导出 Cookie、令牌或密码，不另开无登录态的浏览器。单次任务使用一个 TaskSpace，后续轮次复用本次实际返回的 spaceId；不要复用历史示例 ID。

## 实例定位

控制台： https://console.compshare.cn/light-gpu/console/resources

按实例 ID 核对行，名称与 IP 辅助确认；地址和状态以当前页面为准。在线不等于空闲，SSH 与任务/队列检查通过后才复用。已处于目标状态就报告现状，不重复操作。登录态失效时让用户在 Ego Lite 完成登录后继续；用户接管或访问被拒绝时停止，不换通道绕过。

## 开机

1. 打开实例列表，读取新 snapshot，定位目标行的“启动”（不要误点顶部批量操作）。
2. 点击启动；有平台确认则核对实例后确认。开机恢复按量计费，不因已授权开机再次询问。
3. 等待该行显示“运行中”，并核对“登录”入口恢复。仅点击成功或出现“启动中”不算开机完成。
4. 记录当前实例 ID、状态和公网 IP。若后续还要渲染，再单独核验 SSH 和运行环境；控制台运行中不证明 SSH 已就绪。

## 关机

## 页面定位与验证

- `page.click()` 接受字符串，如 `'ref=29'`，不接受 `{ref:29}`。ref 只属于当前 snapshot；页面变化后重新取 snapshot，不能硬编码旧编号。
- 复选框可能没有出现在 snapshot 中。可用 `page.evaluate()` 读取当前可见弹窗 DOM，再用实际存在的选择器点击；已验证页面使用 `.uc-fe-modal-footer .uc-fe-checkbox`，但不假定它永远不变。
- 状态列可能在横向滚动区域之外。可读取当前目标行 `innerText` 或横向滚动查看；不要因为 snapshot 没显示状态就猜测。已验证目标行有 `data-row-key` 等于实例 ID。
- 等待状态使用不超过 45 秒的有界等待，长时间处理中持续简短更新；失败时报告实际原因，不把受理当成功。
- 完成后按 Ego Skill 结束本次 TaskSpace。用户原有标签页不受影响。
- 只记录必要的实例 ID、动作、时间、最终状态与错误；操作记录不保存或输出凭证，不把完整控制台 DOM 当长期日志；明确授权单独保存的 SSH 资料见 [私人连接资料](private-connection.md)。
