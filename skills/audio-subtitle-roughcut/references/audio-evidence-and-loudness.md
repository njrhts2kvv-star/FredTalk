# 音频剪切证据、残留与整条响度

音频正确、字幕识别有误时，只改文字。ASR给出的词和时码是定位线索，不能单独证明声音里的重复或精确字头。以下要求用于新处理和当前返修，不追溯重做旧交付。

## 先判定问题，再决定是否剪声音

| 当前证据 | 默认处理 |
| --- | --- |
| ASR多字/重复，声音正常；用户也确认是识别错误 | 只校字幕，保留音频；已经误剪时撤回相关刀、恢复被删PCM及必要邻域，保留用户手改文字 |
| 用户指出实际声音有重说、残尾；或已听到两个真实发音 | 定位实际声音，删失败一遍，保护完整后一遍和字头/尾音 |
| ASR写了短词重复，但尚未证明两个真实发音 | 作为禁用候选，先保留音频；核对短段和上下文，不直接启用句内刀 |
| 单一波形二峰、低电平、confidence=1、两次ASR同样写法 | 都不单独证明真实重说；发音可能跨多峰，识别也可能重复出错 |

句内短词删除前，把“删哪遍、保留哪遍、声音证据来自用户反馈还是实际听审、切点是否估算”写进当前cuts的reason/confidence或本期已有决策记录。`reviewed`只表示真实听审/确认状态；写了理由、技术校验或静音播放不改变它。不要为此新增Fred逐刀审批。

用户手改字幕不等于授权剪音频。先读实际subtitle-edits、句子覆盖和禁用刀，不能从旧ASR重新生成状态把手改覆盖掉。若用户已确认是识别多字，不再以“待听审”保留那条误剪；在旧导出里检查该刀是否仍生效并修复声音、字幕和映射。

## 删除重说后查前后残留

- 从原源到剪后接缝检查整个发音单元：失败起句、短词、半个辅音/尾音、吞咽、旁边空隙和后一次完整表达。不要只看整句字幕是否消失。
- ASR常把前一词结束算晚，或把后一词起音算晚。删点先核对实际发音包络，再在保护有效字音的空隙落刀；不固定向前减某个秒数。
- 用户指出残留后，检查删点是否已切进“还/是”等起音。必要时对同一短段重新识别、对齐和观察波形，保留原识别记录；不能只删除字幕或不核声音地把旧时码抄一遍。
- 全篇检查同类问题，给每个候选准确位置和保留/删除理由。局部返修不因此重洗整轨；未改PCM逐样比较，淡化范围另外记录。波形能辅助定位，不能识别词意、吞咽或证明听感。

## 插入声音先核角色和准确源

纯旁白、带动作音效的动画混音、BGM、录屏源声分别登记。字幕同文、文件名相似、帧数接近或hash相同，都不能证明它是纯旁白。先核对用户选中的实际文件/链接目标、hash、采样数和已处理状态，并记录有没有原声/SFX；hash只证明身份，不证明无音效。

用户只要求配音时，优先其明确指定的纯旁白；不从动画MP4、后期混音或同名“过渡动画.WAV”代替，也不靠降噪去除已经混入的动作声。没有可确认的纯旁白时报告准确缺口。Fred固定配音的当前依赖由主Skill `references/fixed-skill-library-insert.md` 和其manifest查询，不固定旧秒数。

## 整条响度不能只看一个LUFS

1. 以实际当前最终音轨分析全片：综合LUFS、LRA、采样/真峰值，以及覆盖全时段的400ms瞬时/3s短时响度。给补录、插入旁白、录屏原声/演示、音效/BGM等实际职责标区间，不能把设计上有意变化的源声统一当成异常。
2. 对同职责声音比较正文、插入前后和插入内部的每句话。几秒素材平均值接近，第一句仍可能突响。短句、含停顿整段、400ms、3s和全片综合LUFS是不同统计量，不混作同一个目标；不足窗口的条目记录无可用测量，不能填0 LUFS。
3. 自动阈值只提出复查位置，结合语义、波形和真实听审决定。正文的自然重音/呼吸、章节演示和用户认可的源声不机械压平；不把某一期的LUFS、音量衰减、秒数或窗口候选数量变成固定配额。
4. 只调整明确不匹配的插入/补录区间，先选同职责的本期正文参考。已处理配音不重复自然链、1.1倍速或+8dB。整段增益足够则用整段，内部句子确实不均匀时再做小幅、平滑的局部音量变化；不默认每一句归一化。不改语速和时长，不硬切音量。必要的峰值保护只在需要的范围做，并复测。
5. 调整后复测实际最终文件，给带前后文的短试听；记录相对原音的实际衰减/增益、局部峰值保护、时钟/字幕hash及未改PCM。保留原配音资产，按本期要求匹配的派生版不覆盖跨期原件。当前声音、字幕、审片台和下载指向同一版本。

### 只读分析工具

`verify_delivery.py`现会生成完整响度轨迹报告，默认从final-delivery的transition/replacement推导职责，其他源声职责由`loudnessSegments`显式提供。报告按音频hash、分段/字幕身份及分析脚本hash命名，不修改音频、字幕、cuts或手改状态。`technicalPass`不代表响度候选已听审或已处理。

也可独立运行：

```bash
python3 scripts/loudness_profile.py --audio /absolute/final.wav \
  --segments /absolute/loudness-segments.json \
  --cues /absolute/cues.json --output /absolute/loudness-profile.json
```

输入为规范PCM16 WAV；segments为不重叠的最终音频秒区间列表，例如`[{"id":"intro","role":"narration","start":0,"end":20},{"id":"insert","role":"insert","start":20,"end":25}]`。不相关区间可不列出；工具不猜声音角色。cues为`[{"start":0.1,"end":1.5,"text":"实际字幕"}]`，可与segment重叠。可调`--threshold-lu`只改变候选阈值；不表示输出目标音量。

报告包括timeline、整条峰值/综合指标、同职责reference、segments/cues的局部窗口摘要及候选。统计只使用完整落在区间内的窗口，不借前后正文填充短插入/短cue；静音、门限以下和未填满窗口为null。FFmpeg最后不足100ms的尾部可能没有独立轨迹点，coverage记录该差值，整条真峰值/综合指标仍包含完整文件；不虚构最后一个窗口。它不会自动听审、识别重说/口腔声、剪切或调音，也不自动认定声源干净。

## 本次错误形成的通用规则

- “接着往下下移”在ASR里多了字，实际只说一个“下”：字幕改“接着往下移”，不能把正常发音剪掉；若误剪则恢复声音。
- “还是…”整句已删除但前面残了起音：查词时码前后的声音，保护“打字”尾音，不能只复用句级起点。
- 插入素材整体LUFS接近正文，但首句偏响：检查内部各句和前后文，必要时平滑局部衰减，不叠加全片处理。
- 同四句字幕也可能对应纯配音和动画/SFX混音：身份及职责分别核对。本期具体切点、衰减和反馈状态留在本期记录，不作为下一期参数。
