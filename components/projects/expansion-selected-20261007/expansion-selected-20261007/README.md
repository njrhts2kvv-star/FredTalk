# FredTalk 用户精选14个组件

本包仅含本轮明确保留的 OP02、OP03、OP05、OP09、OP10、EX05、EX08、RC01、RC02、RC03、RC04、RC05、HD02、HD03。
分类为画面呈现与交接、讲解和录屏聚焦；用户没有把这批认可为吸睛开头。

先运行 `npm install`，再运行 `npm run check`、`npm run list`。
渲染示例：`node render.cjs render OP02 output.mp4`；加 `--4k` 以3840×2160舞台渲染。
浏览器默认使用本机Chrome，可通过 `FRED_BROWSER_EXECUTABLE` 指定。

默认示例为1920×1080、60fps、无音轨，保留准确字体、媒体和动作时钟。
本轮只有 OP02 另保存真实原生4K60例片；公开网页默认统一使用当前已选1080p60例片。
录屏阅读区间按组件内部clock暂停源媒体，镜头动画继续；新ROI、源视频或clock需重新核对。

这是当前14个示例及准确源码的认可，不能扩为所有新文字、素材和参数组合已通过视觉验收。
字体与现有媒体随相对public路径保留；无本机凭证、私人BGM/旁白、历史意见或构建缓存。
本包不包含另外16个被剔除候选的默认composition或公开视频。
