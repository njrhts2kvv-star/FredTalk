# 交互组件组

4类组件，6种预览。npm install 后 npm run list；npm run render -- Yellow-Camera-First 可渲染单条。默认串行渲染。Codex声音混合另需Python、numpy、ffmpeg；可设置CHROME_PATH指定浏览器。微信默认PingFang SC，需要机器有该字体；改字体需检查换行。

新闻支持parallel/camera-first。Codex以真实截图驱动，prompt必须匹配消息与回复截图及ROI，播放媒体时钟连续。微信消息、姓名、转发卡数据可编辑。保留的旧动作与Codex已获用户取舍；新增时序和中性内容经过内部检查，未另作用户完整审片批准。

本包无私人BGM、凭证、缓存或本机配置。包含本次截图与第109期示例动画，仅作为此组件示例依赖。
