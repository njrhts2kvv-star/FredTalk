# 纳挼崩音黑 （NanoTikBazHei）

![m0](m0.png)

## 字体简介
该字体的原版字体——**抖音美好体**在2023年发布，该字体是由方正和抖音联合共同推出的一款以OFL开源的字体。

该字体仅支持GB2312字符集，然而我发现某些视频中使用该字体时偶尔会出现缺字的情况，且这个字体的衍生版本少之又少，那我们能不能解决该字体缺字的情况呢，于是我们持续补字制作出了这个字体——**纳挼崩音黑**。
