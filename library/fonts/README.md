# FredTalk 字体

日常使用的五个字体家族直接随源码提供，无需先下载 Release 素材包。共八个文件，约 53 MiB；Release 中仍保留同一版本。

| 字体 | 文件 | 许可与来源说明 |
| --- | --- | --- |
| MiSans | `MiSans-Regular.otf`、`MiSans-Medium.otf`、`MiSans-Semibold.otf`、`MiSans-Heavy.otf` | [小米字体许可协议](MiSans-License.txt) |
| 锐字真言体 | `RuiZi.ttf` | [原字体提供方的免费使用说明](RuiZi-official-free-use.txt) |
| 得意黑 | `SmileySans-Oblique.ttf` | [字体许可](SmileySans-LICENSE.txt) |
| 霞鹜文楷 | `LXGWWenKai-Regular.ttf` | [SIL Open Font License](LXGWWenKai-OFL.txt) |
| Source Code Pro | `SourceCodePro-Semibold.ttf` | [字体许可与版权说明](SourceCodePro-LICENSE.md) |

文件保持原始字形与二进制内容。准确 SHA-256、字重和用途登记在 [字体注册表](../../skills/fred-remotion-output/references/typography-registry.json)。MiSans 的 CSS 字重映射与文件内部 OS/2 数值存在差异，使用登记的实际文件，不合成粗体。

复制到自己的工程后，按该工程的字体加载方式引用；随字体保留对应许可与版权说明，各字体按其自身条款使用和分发。
